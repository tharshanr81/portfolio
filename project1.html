Project 1: Multiple Form Filler

Why: To avoid filling the same details repeatedly and save time.

How: Built using Python Selenium for automation, with MySQL storing user data.

What: A tool that automatically fills multiple web forms using saved data.

Impact: Reduces time by ~70%, handles multiple websites, and minimizes errors.

Tools Used: HTML, CSS, JavaScript, Python, Selenium, SQL.

Role: Full-Stack Developer – designed UI, built automation, and integrated database.

Key Features:

  • Auto-fill multiple forms instantly
  • Stores and reuses user data
  • Supports dynamic form fields
  • Reduces manual errors
